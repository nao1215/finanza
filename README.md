Decimal numbers, money, interest and payment card helpers for Gleam, on
the Erlang and JavaScript targets.

```sh
gleam add finanza
```

## Usage

Adding sales tax to a price, rounded to the cent:

```gleam
import finanza/decimal
import finanza/money
import gleam/result

pub fn price_with_tax() -> Result(String, money.MoneyError) {
  let assert Ok(price) = money.from_minor(9999, in: money.usd)
  let assert Ok(rate) = decimal.parse("0.08")
  use tax <- result.try(money.multiply(price, by: rate, rounding: decimal.HalfEven))
  use total <- result.map(money.add(price, tax))
  money.format(total, with: money.default_format)
  // -> Ok("$107.99")
}
```

Splitting a bill three ways without losing the remainder, and formatting
for a German invoice:

```gleam
import finanza/money
import gleam/list
import gleam/result

pub fn split_bill() -> Result(List(String), money.MoneyError) {
  let assert Ok(bill) = money.from_minor(100_000, in: money.eur)
  let german =
    money.FormatOptions(
      ..money.default_format,
      thousands_separator: ".",
      decimal_separator: ",",
      symbol_position: money.Suffix,
    )
  use parts <- result.map(money.allocate(bill, [1, 1, 1]))
  list.map(parts, money.format(_, with: german))
  // -> Ok(["333,34€", "333,33€", "333,33€"])
}
```

A monthly mortgage payment and the first row of its schedule:

```gleam
import finanza/decimal
import finanza/interest

pub fn mortgage() -> #(String, String) {
  let assert Ok(principal) = decimal.parse("200000")
  let assert Ok(rate) = decimal.parse("0.005")
  let assert Ok([first, ..]) =
    interest.schedule(principal:, rate_per_period: rate, periods: 360, digits: 2)
  #(decimal.to_string(first.payment), decimal.to_string(first.interest))
  // -> #("1199.10", "1000.00")
}
```

Checking and masking a card number:

```gleam
import finanza/card

pub fn card_details() {
  #(
    card.validate("4111 1111 1111 1111"),
    // -> Ok(card.Visa)
    card.mask("378282246310005", with: card.default_mask),
    // -> Ok("3782 **** *** 0005")
    card.parse_expiry("12/28"),
    // -> Ok(card.Expiry(month: 12, year: 2028))
  )
}
```

## Notes

- A decimal's exponent is between -28 and 15, so it has at most 28 places, and its coefficient, and the integer a positive exponent stands for, stay within ±9,007,199,254,740,991 (2^53 − 1) on both targets, so results match on Erlang and JavaScript. Results outside the range are `PrecisionExceeded` errors, and `decimal.parse` rejects such values and any input over 1,000 bytes, so untrusted text cannot make a huge value. A result whose exponent is out of range drops the fewest trailing zeros that bring it into range, so `parse("0.10000000000000000000000000000")` is `0.1000000000000000`.
- The interest functions round the exact value once, half-even, so they give the same result as Python's `decimal`; `test/differential/python_test.gleam` checks this against cases generated by `scripts/python_differential.py`. Each call does a bounded amount of work whatever its inputs, and the `card` functions reject input over 1,000 bytes as `decimal.parse` does.
- The 15 built-in currencies and the card brand rules are snapshots taken in May 2026. There is no exchange rate lookup or BIN database.

How the package is tested is described in [doc/testing.md](https://github.com/nao1215/finanza/blob/main/doc/testing.md).

## Verifying releases

Each GitHub Release attaches the tarball published to Hex (`finanza-<version>.tar`), `checksums.txt`, a cosign signature bundle (`checksums.txt.sigstore.json`) and build provenance (`finanza-<version>.intoto.jsonl`). The release workflow downloads the tarball from Hex after `gleam publish` and checks it against the checksum Hex records before signing it, so the tarball you get from Hex is the one that is signed and attested.

```sh
curl -fsSLO https://repo.hex.pm/tarballs/finanza-<version>.tar
gh attestation verify finanza-<version>.tar --repo nao1215/finanza
```

To check the signature as well, download `checksums.txt` and `checksums.txt.sigstore.json` from the Release into the same directory. The workflow runs on the release tag, or on `main` when the assets of a published tag are attached again.

```sh
cosign verify-blob \
  --bundle checksums.txt.sigstore.json \
  --certificate-identity-regexp '^https://github\.com/nao1215/finanza/\.github/workflows/release\.yml@refs/(tags/v.+|heads/main)$' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  checksums.txt
sha256sum --check checksums.txt
```
